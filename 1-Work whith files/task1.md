# Работа в консольке

1) Переместиться между директориями
Ответ: Для перемещения между директориями есть команда cd(change directory) Общий синтаксис cd [имя директории]
2) Вывести список файлов в директории
Ответ: Для вывода всех файлов команда ls(list), у неё есть множество флагов, так например ls -a выводит все скрытые директории
3) Вывести список Всех файлов в директории
Ответ: ls -a или ls -l. ls - l - вывод в длинном формате: перед именами файлов выдается режим доступа, количество ссылок на файл, имена владельца и группы, размер в байтах и время последней модификации (см. ниже). Если файл является специальным, то в поле размера выводится старший и младший номера устройства.
4) Создать папку с подпапками
Ответ: mkdir [название папки] - создаёт пустую папку, mkdir -p [папка 1][папка 2][...] - создаёт любую необходимую вложенность
5) Внутри папки создать файлик и записать в него что-нибудь
Ответ: Существует два варианта решения. Первый наиболее интуитивный при помощи команды echo, которая по своей сути выводит содержимое в консоль написать echo "Нужный текст" > example.txt, команда > - перенаправит вывод из консоли в файл example.txt и если его нет, создаст. Другой вариант командой touch example.txt - создать файл и при помощи одного из редакторов кода( vim/new vim/nano) написать нужный текст. Плюс такого варианта в более расширенной функциональности, однако если текст небольшой, лучше отдать предпочтения первому варианту
6) Переместить файл из одно директории в другую
Ответ: mv [путь к исходному файлу] [путь до нужной директории]
7) скопировать файл из одной директории в другую
Ответ: cp [путь к исходному файлу] [путь до нужной директории]
8) переименовать файл
Ответ: mv -i [файл1] [файл2] преимуществом использования флага -i является то, что так мы исключим случайного переименовывания файла, потому что потребуется дополнительное подтверждение
9) сравнить содержимое файла
Ответ: diff [опции] [файл1] [файл2] При помощи различных флагов в параметре опций можно выводить как различия, так и совпадения(флаг -s) или убрать учитывание пустых строк(-B) или не учитывать пробелы(-b). Помимо этого возможно выводить данные в любом необходимом формате.
10) отсортировать содержимоей файла по возрастанию и убыванию
Ответ: sort [имя файла] - сортировка по возрастанию, sort -r [имя файла] - сортировка по убыванию
11) удалить все папки и файлы
Ответ: rm -r [имя директории], rm -rf [имя директории] - менее предпочтительный в большинстве случаев вариант, так как он рекурсивно удалит содержимое всего файла без подтверждения
