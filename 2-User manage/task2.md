
# Запрещаем

1. Запретите пользователю user1 из предыдщуего задания выполнять вход в систему
Ответ: sudo usermod -L user1
2. Как вы это сделали?
Ответ: команда sudo usermod -L user1 , которая блокирует учетную запись пользователя user1. При этом войти в систему ни по паролю, ни по ssh не получится. При попытке входа система будет выдавать ошибку.
3. Какие ещё способы это сделать вы знаете?
Ответ: usermod -s /bin/false, - оболочка с тихим отказом, change -E 1970-01-02 user1 - учётная запись истекла
4. Можно ли создать пользователей с одинаковыми username?
Ответ: Нельзя, так как каждый пользователь должен иметь уникальный идентификатор, а также username является ключом в файле паролей
