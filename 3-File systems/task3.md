# Продолжаем

1. Выведите содержимое fstab. Что хранится в fstab?
Ответ: В fstab хранится таблица автоматического монтирования файловых систем при загрузке системы.
Вывод содержимого в fstab находится в файле <span style="color:blue;">task 3.3.1.png</span>
2. Добавьте в виртуальную машину ещё один диск
Ответ: Снимок в файле <span style="color:blue;">task 3.3.2.png</span>
3. Узнайте как ситема видит ваш диск - выведите информацию о блочных устройствах
Ответ: Снимок в файле <span style="color:blue;">task 3.3.3.png</span>
4. С помощью полученной информации создайте на диске таблицу разделов и фаловую систему ext4
Ответ: Снимки: <span style="color:blue;">task 3.3.4(1).png, task 3.3.4(2).png, task 3.3.4(3).png</span>
5. Примонитруте диск в каталог /mnt
Ответ: Снимок в файле <span style="color:blue;">task 3.3.5.png</span> При помощи команды df с флагов -h(human readable) мы получаем информацию обо всех смонтированных файловых системах, в человекочитаемом формате
6. Зайдите в каталог и создайте там файлы
Ответ: Снимок в файле <span style="color:blue;">task 3.3.6.png</span>
7. Отмонтируйте диск и проверье остались ли файлы
Ответ:  Чтобы проверить остались ли файлы я ещё раз монтирую диск и вывожу содержимое файла. Таким образом после того как мы отмонтировали диск файл остался. Снимок в файле <span style="color:blue;">task 3.3.7.png</span>
8. Сделайте так чтобы диск автоматически подключался при загрузке систем ( добавьте информацию о нём с fstab)
Ответ: Ответ: Снимки в файлах <span style="color:blue;">task 3.3.8.png, task 3.3.8(2).png.</span> В самом начале при помощи команды blkid мы узнаём UUID(уникальный идентификатор) нашего диска, а затем при помощи nano записываем данные в файл
9. Проверьте корретность записанных в fstab данных перед перезагрузкой
Ответ: Командой mount -a выполняем автоматическое монтирование всех файловых систем, так как команда была выполнена без ошибок, значит данные корректны
10. Перезагрущите систему и убедитесь что диск был подключён к системе
Ответ: После перезагрузки диск был подключен к системе
