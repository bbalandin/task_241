6. Что такое ip адрес?
Ответ: Логический идентификатор устройства в сети, используемый для маршрутизации трафика
7. Для чего нужны маршруты?
Ответ: Без маршрутов устройство не знает, куда отправлять пакеты вне своей локальной сети.
8. Что за протокол arp?
Ответ: Address Resolution Protocol — преобразует IP-адрес в MAC-адрес (физический адрес сетевой карты) в локальной сети.
9. Что такое dhcp?
Ответ: Dynamic Host Configuration Protocol — автоматически выдаёт устройствам IP-адрес, маску подсети, шлюз, DNS-серверы.
Таким образом, не нужно вручную настраивать сеть для каждого устройства
10. Что такое dns?
Ответ: Domain Name System — преобразует домены в IP-адреса
11. Как называется один из протоколов синхронизации времени?
Ответ: NTP (Network Time Protocol) — синхронизирует время устройств с атомными часами через интернет.
12. Что такое широковещательный запрос, зачем он нужен?
Ответ: Широковещательный запрос это пакет, отправленный всем устройствам в локальной сети. Нужен для ARP-запросы, DHCP-запросы,
обнаружения устройств
13. Какой адресс является широковещательным?
Ответ: универсальный: 255.255.255.255 (ограничен broadcast-доменом).
14. Какие ещё параметры можно задать сетевой карте?
Ответ: MTU (Maximum Transmission Unit) — размер пакета, Duplex (full/half) — одновремённый приём/передача,
Speed — скорость (100M/1G/10G), MAC-адрес (перезапись для анонимности), 
15. Что такое маска подсети? зачем она нужна?
Ответ: Маска подсети это число, разделяющее IP на сеть и хост. Помогает определить устройства в локальной сети, позволяет роутеру группировать устройства для эффективной маршрутизации.
